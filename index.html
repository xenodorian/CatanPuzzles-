⚙ DM Configuration

The matrix contains 9 cells in a 3×3 grid. The bottom-right cell is missing, and players must identify the pattern (by row, column, or diagonal rules) and select the correct answer from six options. Each puzzle uses ONLY shapes that appear in the grid, with multiple shapes per cell for greater complexity.
