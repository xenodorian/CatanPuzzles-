"A heavy iron lock seals the iron chest, its dials engraved with ancient runes. The inscription below reads: The number of moons in a season, the legs of a spider, and the year's final count."

⚙ DM Configuration

Set the solution below. The default is 3 · 8 · 12 (moons in a season · spider legs · months in a year). Change LOCK_SOLUTION and LOCK_RIDDLE in the script to customize. You can also change LOCK_SYMBOLS to use rune glyphs instead of numbers.

"Stone channels carved into the floor of the chamber. Water flows from the glowing golden source. Rotate the carved tiles until the flow reaches the green seal."

Rotations: 0
⚙ DM Configuration

Click any non-source/target tile to rotate it 90°. The puzzle auto-generates a solvable path. Players click tiles to rotate them and then press Check Flow. The puzzle highlights the connected path in teal when solved.

⚙ DM Configuration

Click any tile adjacent to the empty space to slide it. Change SLIDER_GLYPHS in the script to swap symbols (use numbers, letters, or emoji). The goal order is shown above the grid. Works best on desktop; mobile drag coming soon.

"Five glyphs must be pressed upon the altar in the correct order. The ancient text reads: "

⚙ DM Configuration

Change SEQ_SOLUTION to set the correct order (indices into SEQ_SYMBOLS), and edit SEQ_RIDDLE to give players the in-game clue. Players tap symbols to build the sequence; order matters.

"A stone tablet of rune-circles, some glowing, some dark. The pattern on the left wall shows what must be illuminated. Click the circles to toggle them — but beware, each touches its neighbours."

Presses: 0
⚙ DM Configuration

Two modes: Pattern Match (click cells to match the target pattern shown in the legend) and Lights Out (clicking a cell also toggles its neighbours — must turn all off). Edit TOGGLE_TARGET to set the goal pattern. A 5×5 grid by default.
